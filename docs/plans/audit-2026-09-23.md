# Fresh-eyes audit — 2026-09-23 (findings and ideas, nothing built)

Read-only audit at HEAD `34d7bcd` (clean tree). Scope: frontend, code quality, hygiene, product and
big picture. Out of scope by design: everything ear- or rig-gated (latency, sync, click feel).
Nothing here is fixed; this file is the decision material. Per `AGENTS.md`, an audit is not kept in
the tree: when the owner has picked from it, each kept item lands as a commit, a `STATUS.md`
decision row or a `docs/backlog-taste.md` line, and this file is deleted.

**Method.** Lead (Fable 5.1) scouted and wrote the briefs; five readers ran in parallel: two
`opus @ high` (UI/UX with Playwright screenshots of the browser tier; product big picture), two
`gpt-6-sol @ high` (TypeScript; Rust), one `gpt-6-luna @ high` (hygiene). Astra was not used. The
lead re-read the source for every item marked **[verified]**; items marked **[reader]** are a
reader's claim with a citation the lead did not re-check. Nothing already in `STATUS.md`,
`docs/backlog-taste.md` or `docs/plans/tester-feedback.md` is repeated.

**Not rendered:** the native Tauri surfaces (plugin picker, GO LIVE, EDITOR/PARAMS, Audio Settings).
UI findings come from the browser tier at 1280×820, 1920×1080 and 1000×700, keyboard on and off,
with a real first take, an ARMED later take, COPY and the FX drawer driven headless. Screenshots
are on this machine only, under `/tmp/bl-shots/` (not tracked).

## C. Frontend craft and UX (browser tier) — owner's eye or `pnpm check`

- **C1 [verified]** A disabled lane core keeps `title="record"` while another lane records
  (`Looper.tsx:213-238`): the hover promises the action the click refuses. One `recDubGate(i) →
  {ok, reason}` in the looper store would feed the title, the ARIA label and the known silent

## F. Ideas, ranked by the lead (size S/M/L; provenance in brackets)

1. **Refusals explain themselves** (M) [ui]: `recDubGate`/`playStopGate` in the looper store feed
   disabled titles, ARIA and a brief lane cue on a refused Space/Enter. Closes A-class silence
   and the known Space line in one seam.
2. **Copy diagnostics + version in Help + open-log-folder + issue template** (S) [product]: turns
   every tester report from "unknown commit, unknown driver" into a paste. Plumbing exists.
3. **Pedalboard mode as the next milestone** (L) [product] — DECIDED, see `docs/plans/pedalboard.md`: MIDI learn for ~8 looper actions +
   UNDO/next/prev keystrokes (M) + rig recall of slot/plugin/state/live flag (M) + the parked
   stage view. Changes how every session feels; needs no rig to prove correctness. Explicitly not
   next: D12, native looper core, scenes, input FX, panel drag, Day/Night, more synths.
4. **Multiply: a later take may be k× master, re-tiling existing lanes** (L) [product]: removes
   the first-take ceiling (D-b) with the existing `commitLaterTake` tiling.
5. **FREE first take that sets the tempo + 3/4 and 6/8** (M) [product]: D-c; whole-bar master
   invariant holds because the grid is derived from the take.
6. **Recent-jams shelf** (M) [product]: keep the last N recovery archives on ✕ ALL and close;
   surface them in IMPORT, which is already enabled exactly when the looper is empty.
7. **Screenshot contact sheet in `verify/`** (M) [ui]: fixed viewports, keyboard on/off, count-in,
   armed, FX, Help. Would have caught A3 and A4 and gives the eye-lap a stable artefact.
8. **Per-lane pan** (S) [product], **resample on import/recovery** (S) [product],
   **README "Play it" above "Build it" + refreshed hero** (S) [product].
9. **One `.pill` primitive + five type tokens** (M) [ui]: makes the owner's live-HMR token
   sessions apply app-wide. **First-run cue only on the selected empty lane** (S) [ui].
10. **Built-in dry INPUT source** (M, Rust effort unknown) [product]: native passthrough with no
    plugin, so GO LIVE works before the user owns an amp sim.
11. **Rhythm guide** (M, ear-gated) [product]: three GM-kit grooves on the master pulse as an
    alternative to the click.
12. **Hosted browser demo on Cloudflare Pages** (S) [product]: contradicts the standing "browser
    tier is not a product" rule; owner's call.
13. **Shared CLAP/VST3 load owner + stable IPC error codes** (M) [rust].
