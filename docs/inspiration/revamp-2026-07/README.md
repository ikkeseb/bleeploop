# The looper-UI spec

`orbit-v2-lanes.html` is THE approved looper-UI spec ("Orbit V2 · Lanes"): dark surfaces, linear
waveforms (per-pixel peak/body envelope), a bar grid and five full-width horizontal lanes. It is
self-contained static HTML with no audio wiring: open it directly, or serve it via the dev server
(`http://localhost:1420/docs/inspiration/revamp-2026-07/orbit-v2-lanes.html`).

Composition it fixes: the looper is the hero (~65% of the height), one command bar owns the whole
transport, the source row is compact and the keyboard is a thin ribbon.

Where production deliberately differs from the mockup: `src/ui/AGENTS.md`.
